# Pact Backlog

This lane stores deferred Pact feature task folders that are intentionally
outside the approved testnet MVP path. Examples include production card
issuance, fiat settlement, multi-chain support, ERC-20 support, provider
fallbacks, and broader multi-agent policy management. Backlog work must not
change the active MVP contracts without an explicit plan supplement.

Relevant context: `process/context/all-context.md` and
`process/context/planning/all-planning.md`.
